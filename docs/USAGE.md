# 使用说明与常见问题

适用于 v0.4.7 默认工作台。本文介绍已经公开的常规流程，不要求开启实验功能。

## 1. 下载与启动

从 [Releases](https://github.com/wolassaaa/wallpaper-studio/releases) 下载 Windows x64 版本。

- **便携 ZIP，推荐**：完整解压，再运行文件夹内的 `WallpaperStudio.exe`。不要单独移动 EXE 或删除配套组件。
- **单文件 EXE**：双击运行。启动时需要解包组件，首次打开可能比目录版慢。
- **源码 ZIP**：用于开发，不是安装包；需要 Python 3.12 和项目依赖。

视频编辑使用内置 FFmpeg。Scene / Web 的完整画面由已安装的 Wallpaper Engine 渲染；RePKG 负责内部资源解包，不代替场景渲染。

## 2. 添加素材：不需要使用作者的路径

在左侧素材库输入路径并回车，或点击“添加路径…”选择目录。可添加 Steam 库根目录、Workshop 的 `431960` 目录，或单个壁纸项目目录。

Workshop 项目的常见相对位置是 `steamapps/workshop/content/431960`，实际盘符和 Steam 库位置由你的安装决定。支持多个路径；“移除此路径”只移除库配置，不删除原文件。

也可导入单个视频、选择项目目录，或将支持的文件拖入工作台。素材列表可按标题、类型、标签与分级筛选；标签和分级来自项目元数据，未标注的项目不会自动当作全年龄。

## 3. 先预览，再录制

### 已有视频

导入后在后台准备轻量预览和帧时间索引。顶部可选择以下视频预览档位：

| 档位 | 预览长边上限 | 预览帧率 |
| --- | --- | --- |
| 轻量，默认 | 640 像素 | 15 fps |
| 均衡 | 960 像素 | 24 fps |
| 清晰 | 1280 像素 | 30 fps |

这些设置只影响浏览，不会降低正式导出的源画质。首次准备需要时间，长视频和高分辨率视频可能更慢；同一会话可复用已准备的副本和预览。

### Scene / Web

选择项目后可自动启动实时预览，也可在“录制”页手动启动或重启。预览来自工具创建的 Wallpaper Engine 临时窗口，不是列表缩略图。实时场景预览与视频代理不同：采集最长边上限为 1280 像素、最高 15 fps。

1. 确认真实画面已加载，必要时增加加载等待；默认等待 20 秒。
2. 拖动录制时长滑条，或选择 3 / 5 / 10 / 20 / 30 秒快捷值；默认 10 秒。
3. 按需要展开高级录制设置，修改采集尺寸和帧率；默认 3840 × 2160、30 fps。
4. 点击“录制可回放片段”，完成后进入视频编辑流程。

实时场景没有可直接跳转的视频时间轴，先录制才能点播、逐帧和选区间。录制时会关闭本工具的实时预览窗口，再创建录制窗口。任务报告中的实际尺寸、帧率和丢帧，比请求值更能反映采集结果。

“部件”中的选项取自壁纸作者开放的项目属性。项目未开放的粒子、模型或小部件不会自动出现可控开关。

## 4. 时间轴：片段和当前帧是两件事

- **上轨区间**：设置导出片段的起点、终点。
- **下轨播放头**：拖动浏览画面，配合前后按钮逐帧定位。
- **PNG 当前帧**：使用当前选中的帧，不是列表缩略图。
- **批量 PNG**：在起点到终点之间按间隔秒数采样；终点不作为包含在内的采样点。时间点按实际帧时间戳选择，不保证每个采样时间都有完全对应的一帧。
- **GIF / MP4**：使用选中的时间区间，终点必须晚于起点。

精确导出读取原视频的解码帧；播放器拖动预览的近似定位不作为最终导出依据。

## 5. 构图与清晰度

先选择画面比例、方向和输出尺寸，再拖动裁切框。框内拖动可移动位置，右下角可缩放。横竖方向分别记忆构图，但这不等于苹果内置壁纸的自动重新布局。

| 适配方式 | 画面变化 |
| --- | --- |
| 裁切铺满 | 保持物体比例，裁掉部分边缘 |
| 完整保留补边 | 保留整个画面，比例不一致处补边 |
| 拉伸 | 填满目标尺寸，但可能改变人物和物体比例 |

2K / 4K / 8K 在本工具里按长边 2560 / 3840 / 7680 像素定义，另一边根据比例计算。默认设备比例为 iPad Pro 11 M4，横向 2420 × 1668、竖向 1668 × 2420。

**渲染尺寸、预览尺寸、输出尺寸互相独立。** 场景可以请求更高原生采集尺寸，但开销会增加；视频输出倍率只增加文件像素，不恢复裁切时丢失的细节。把低分辨率裁切结果放大三倍，仍可能比原图糊。当前未集成 AI 超分或背景生成。

H.264 编码需要偶数宽高；程序提示时，请明确修改尺寸再导出。

## 6. 导出位置和结果文件

点击顶部“设置导出位置…”，选择自己的结果目录；路径会保存供下次使用。不要选择原壁纸项目内部。每次常规导出会在目标目录下创建新的 `export-…` 子目录，避免重复任务覆盖旧结果。

| 导出类型 | 应使用的文件 |
| --- | --- |
| PNG 当前帧 | `frame.png` |
| 批量 PNG | 生成的多张 PNG 图片 |
| GIF | `clip.gif` |
| MP4 | `clip.mp4` |

`edit.json` 和 `variants.json` 是构图、选区等配置记录，不是图片，也不是要导入相册的文件。批量导出本来就会生成多张图片。请根据选择的格式使用最终图片或视频。

原始素材会先复制到独立任务目录。预览、录制副本和处理缓存可能占用额外磁盘空间；普通工作台任务目录位于系统临时目录下的 `WallpaperStudio/jobs`。取消或失败后可能留有中间文件，请在程序关闭后确认目录内容再手动清理，不要删除正在处理的任务文件。

## 7. 常见问题

**扫描不到壁纸？** 检查是否选择了包含已下载项目的 Steam 库。多个 Steam 库需要分别添加；列表筛选也可能隐藏结果。

**读取慢、播放卡？** 先选轻量预览档位，等待后台准备完成。Scene / Web 可关闭自动实时预览；录制时先降低采集尺寸或帧率，再查看实际采集报告。预览清晰度不决定导出清晰度。

**场景是黑屏或还没加载？** 检查 Wallpaper Engine 和项目资源是否正常，增加加载等待并重启预览。暗色壁纸不一定是加载失败，不应只凭接近黑色判断。

**解包出来的图与壁纸不同？** 解包得到的是内部纹理等素材。粒子、模型、动态效果和完整场景需要由 Wallpaper Engine 渲染后采集。

**为什么放大后还是糊？** 输出像素多不等于源细节多。优先减少过度裁切、使用更清晰的源视频，或提高场景原生采集尺寸；高倍率插值不是无损细节恢复。

**导出视频不是 Live Photo？** 默认 MP4 是普通视频。实验性 Live Photo 配对和 iPad 动态识别未完成设备验收，不把生成结构当作 Apple 相册识别成功。

**如何报告问题？** 到 [Issues](https://github.com/wolassaaa/wallpaper-studio/issues) 提供程序版本、Windows 版本、素材类型、复现步骤、请求尺寸和任务报告。公开前去掉私人路径、账号、密钥及真实私人素材；优先使用能复现问题的小型自制素材。

# Wallpaper Studio v0.4.7 — 首个公开预览版

Windows 壁纸录制与视频选帧工具：从素材库找到壁纸，预览或录制，选择片段与封面，再统一裁切并导出。

## 本次收束

- 默认保留素材库、预览 / 录制、逐帧与区间选择、构图和 PNG / GIF / MP4 导出。
- 隐藏未完成设备验收的 Live Photo、iPad 专用预设和单张横竖适配入口；实验代码保留。
- 不继续扩展 AI 超分、背景生成或自动重排。
- 整理中文说明、许可证、可复现构建与发布资产。

## 应该下载哪个

- 推荐：WallpaperStudio-0.4.7-win64.zip。完整解压后运行 WallpaperStudio.exe。
- 单文件：WallpaperStudio-0.4.7-win64.exe。
- 开发者：wallpaper-studio-0.4.7-source.zip。
- SHA256SUMS.txt 用于核对三个下载文件的哈希。

## 已知事项

这是预览版。iPad Live Photo 识别未通过，AI 超分与背景生成未完成；提高输出像素不等于提升真实细节。场景和 Web 渲染依赖 Wallpaper Engine。全新无 Python 的 Windows 环境独立验收待完成。

源码包不包含真实壁纸、私人照片和测试输出。欢迎报告可复现的启动、录制与导出问题。
